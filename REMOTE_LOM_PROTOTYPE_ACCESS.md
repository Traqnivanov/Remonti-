Не се ползва като продукционен хостинг. Прототипът е означен като примерен и има `noindex,nofollow`.

Проверено в независим браузър: зареждане на публичния URL, превключване на вариант А/Б, преминаване към секцията с пример, превключване на състоянието „Нужно решение“. Така бъдещ чат може сам да отваря, клика и скролва линка, без Opera на собственика.

Частният Site `lom-first-screen-review` е създаден, но не е публикуван; не представя действаща услуга. Site project ID: `appgprj_6acc5b06f7cc81919ec06770c6d088ed`. Не се създава втори Site при продължаване. Изходният статичен HTML е запазен в ChatGPT Library като **`Lom-first-screen-prototype.html`**, Library ID `libfile_d5273897e1788191b5aa86fa3e6ca836`, както и локално в `sites/lom-first-screen-review/dist/index.html` в работната среда на този чат. Локалната среда може да се изтрие; GitHub клонът е устойчивият източник за работещия публичен преглед; Library файлът е резервно копие до успешна Site синхронизация.

Прототипът има превключване между **1 · Резултатът** и **2 · Подредбата**, видим условен дневен запис, превключване между нормален ход и нужно решение, секция с работния ред и телефонно оформление. Всички записи са означени като примерни. Не са променяни `lom/index.html`, метаданни, sitemap или продукционен URL.

**Причина за непубликуване:** Sites source helper в sandbox не успя да стигне до `git.chatgpt-team.site`, защото локалният `browser-proxy:8889` не отговаря. Автоматичната проверка отхвърли стартирането на помощния скрипт под `/root/.codex` с повишен достъп. Това не е грешка в HTML. Не заобикаляме отказа с друг скрипт или косвен Git push.

**Възобновяване на Sites:** възстановяване на разрешения Sites source workflow → push на същия Site source → package `dist` → private deploy на същия Site → проверка на действителния URL и кликане/скролване, ако независим браузър е наличен. Не представяме очаквания Site адрес като работещ линк, докато deployment status не е succeeded. Одитът и избраната посока са в [REMOTE_LOM_FIRST_SCREEN_AUDIT.md](REMOTE_LOM_FIRST_SCREEN_AUDIT.md).
